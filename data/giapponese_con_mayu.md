## 📌 Note grammaticali generali

- L'ordine delle parole è **SOV**: Soggetto → Oggetto → Verbo
- Il **verbo va sempre alla fine** della frase
- Le **particelle** definiscono il ruolo di ogni parola nella frase
- Il soggetto si omette spesso se è ovvio dal contesto
- Non esistono articoli (il/la/un/una)
- Non esiste il plurale formale

### Particelle fondamentali

| Particella | Funzione | Esempio |
|---|---|---|
| は (wa) | Tema / soggetto generale | 私は = "parlando di me…" |
| が (ga) | Soggetto specifico / enfatico | 何が = "cosa (in particolare)" |
| を (wo) | Oggetto diretto | ピザを = "la pizza (che mangio)" |
| に (ni) | Destinazione / tempo | 学校に = "a scuola" |
| で (de) | Luogo dell'azione | 学校で = "a scuola (dove avviene)" |
| の (no) | Possesso | 私の = "mio / di me" |
| と (to) | "e" / "con" | 犬と猫 = "cane e gatto" |
| も (mo) | "anche" | ロックも = "anche il rock" |
| から (kara) | "da" (provenienza) | ナポリから = "da Napoli" |
| か (ka) | Trasforma in domanda | 好きですか？ = "ti piace?" |
| へ (e) | Direzione (simile a に) | 日本へ = "verso il Giappone" |

## ❤️ Preferenze — Mi piace / Non mi piace

### Struttura

```
[COSA] が 好き です         → Mi piace [COSA]
[COSA] が 好き ですか？     → Ti piace [COSA]?
[COSA] が 好き じゃない です → Non mi piace [COSA]

## 📍 Provenienza

### Struttura

```
[luogo] から 来ました → Vengo da [luogo]
どこから来ましたか？  → Da dove vieni? (formale classico)
出身はどこですか？    → Di dove sei? (più naturale)
[luogo] 出身です     → Sono originario/a di [luogo]
```

| Romaji | Giapponese | Italiano |
|---|---|---|
| Doko kara kimashita ka? | どこから来ましたか？ | Da dove vieni? |
| Shusshin wa doko desu ka? | 出身はどこですか？ | Di dove sei originario/a? |
| Napori kara kimashita | ナポリから来ました | Vengo da Napoli |
| Napori shusshin desu | ナポリ出身です | Sono originario/a di Napoli |
| Doko kara kita no? | どこから来たの？ | Da dove vieni? (informale) |

## 💬 Spiegare il perché — Nazenara…kara/dakara

```
なぜですか？                     → Perché? (domanda)
なぜなら + [motivo] + から です   → Perché… (risposta con agg. -i)
なぜなら + [motivo] + だから です  → Perché… (risposta con agg. -na)
```

| Romaji | Giapponese | Italiano |

| Nazenara kirei dakara desu | なぜなら綺麗だから です | Perché è bello/a |

### Gruppo 3 — Irregolari (solo 2!)

| Forma base | Educata | Passato | Italiano |

| する (suru) | します | しました | ho fatto |

### Regola universale del passato educato
```
~ます → ~ました (vale per tutti e tre i gruppi)
tabemasu   → tabemashita
ikimasu    → ikimashita
shimasu    → shimashita
```

## ⚠️ Passato degli aggettivi -i

Gli aggettivi -i **non usano deshita** — hanno una forma propria:

```
aggettivo -i → togli い → aggiungi かったです
```

| Presente | Passato | Italiano |
|---|---|---|
| 難しいです (muzukashii desu) | 難しかったです (muzukashikatta desu) | era difficile |
| 楽しいです (tanoshii desu) | 楽しかったです (tanoshikatta desu) | era divertente |
| 寒いです (samui desu) | 寒かったです (samukatta desu) | faceva freddo |
| 暑いです (atsui desu) | 暑かったです (atsukatta desu) | faceva caldo |
| 良いです (ii desu) | 良かったです (yokatta desu) | era bello / meno male ⚠️ irregolare |

> ⚠️ **よかったです (yokatta desu)** è irregolare — viene da 良い (yoi) non da いい. È anche un'esclamazione comunissima: "Meno male!" / "Che bello!"

## 🔤 Forma -te — sequenza di azioni

La forma -te collega azioni in sequenza come una virgola tra verbi. Il verbo finale porta la forma completa.
